# Тихе світло / Quiet Light

Двомовний сайт фотографа: українська та англійська, світла й темна теми, адаптивне відео.

## Структура

- `dist/` — готовий сайт, фотографії та відео.
- `scripts/en-copy.json` — англійські переклади.
- `scripts/build-english.py` — оновлює `dist/en.html` з української сторінки та перекладів.

## Локальний запуск

Потрібен Python 3. У корені проєкту виконайте:

```sh
python3 -m http.server 8000 --directory dist
```

Відкрийте http://localhost:8000.

## Редагування

Українська сторінка: `dist/index.html`. Стилі та поведінка: CSS і JavaScript у `dist/`.
Після змін українського тексту додайте переклад у `scripts/en-copy.json` і виконайте:

```sh
python3 scripts/build-english.py
```

## Публікація

Це статичний сайт без залежностей npm і без кроку збірки. Папка публікації — `dist`.
Для GitHub Pages використовуйте процес публікації, що завантажує `dist` як артефакт Pages.
Завантаження файлів у репозиторій саме по собі не вмикає хостинг.

Форма створює локальний текстовий бриф; вона не надсилає дані та не бронює дату.
